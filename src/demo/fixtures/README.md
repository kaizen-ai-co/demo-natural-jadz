# Fixtures de demo

Datos **ficticios** para las demos. Reglas:

- Nunca uses nombres, teléfonos ni correos de clientes reales.
- Teléfonos con el patrón `300000000X`. Correos solo con `@ejemplo.test` (dominio reservado, igual que en kaizen-demos).
- Los nombres de asesores llevan «(ficticio)» o «(ficticia)» para que nadie los confunda con el equipo.
- Las ciudades y los servicios deben coincidir con las opciones de `src/content/demos/*.json`.
